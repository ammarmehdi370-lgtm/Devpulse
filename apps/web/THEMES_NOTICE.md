# Theme library notices

The built-in catalog contains compact, independently authored Devpulse color
approximations. It does not bundle upstream theme JSON, source code, fonts, or
assets. Names identify the color themes that informed the palettes; their
respective upstream sources and license files are listed below. Imported VS
Code themes are supplied by the user and stored only in that user's local
browser storage.
